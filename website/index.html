SECURITY NOTE

Powerful access should look powerful.

Local System can execute commands with the privileges of your OS account. It is not an operating-system sandbox. Use restricted project roots, keep the MCP bridge private, and review destructive operations before approving them.

05 / FAQ

Before you connect it.

Does Local System upload my whole computer?

No. Files remain local unless you select them or a tool reads them as part of an authorized request. Tool results and selected content can be sent to ChatGPT; see the privacy/data-flow document for details.

Is the Chrome extension required?

No. The MCP bridge works without it. The extension adds the file workspace, // skill picker, @@ file attachment, previews and annotations.

Can I use ngrok?

Only with an independently configured ChatGPT-compatible authentication layer. Never expose the local /mcp endpoint anonymously.

Which platforms are supported?

The core Node/MCP bridge is CI-covered on macOS, Linux and Windows. Some service, browser and external tunnel paths have more specific limitations.
