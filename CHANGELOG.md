# Changelog

All notable user-visible changes should be recorded here. The project follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) structure and [Semantic Versioning](https://semver.org/) for tagged releases.

## [Unreleased]

### Added

- Beginner-oriented diagnostics that read the normal per-user runtime configuration without printing configured secrets.
- Clean-clone installation/MCP smoke verification and CI coverage for that path.
- Beginner README, Secure MCP Tunnel guide, advanced ngrok security guide, and community contribution/security infrastructure.

### Changed

- Destructive-operation approval is enabled by default.
- Public documentation now distinguishes the working private tunnel path from the not-yet-automated OAuth/ngrok onboarding path.

## [1.0.0] - 2026-10-16

Initial public-source baseline of Local System: the 11-tool MCP bridge, companion Chrome workspace, file/skill composer attachments, previews/annotations, local command/task execution, and platform service scripts.

The repository entered public history with `package.json` already at `1.0.0`. A historical `v1.0.0` tag was not retroactively created; release tags are used prospectively.
